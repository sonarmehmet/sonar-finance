# SONAR FINANCE

Öncelik: alış/satış faturası, stok, depo, cari. Sonra kasa/banka, gider, proje maliyeti, raporlar.

- Başlangıç: `PROGRESS.md` → `CONTRACTS.md` → `docs/`
- Sözleşme: `docs/02-firestore-modeli.md`, `docs/04-islem-akislari.md`, `firebase/firestore.rules`
- Tasarım: `shared/design-tokens.json`, `shared/l10n/tr.json`
- Scriptler: `scripts/*.bat` (Windows)
- Ajan promptları: `docs/AJAN_PROMPTLARI.md`
